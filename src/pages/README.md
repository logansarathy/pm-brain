# pages/

**What goes here:** One file per "screen" a user can navigate to — this
replaces the `renderDashboard()`, `renderWeek()`, `renderPortfolio()` style
functions from your HTML version's router.

Each page is what shows up **inside** the layout when its route is active.

**You will edit this folder:** every time you add/change a screen of PM OS.

**You will NOT put here:** small reusable widgets (those go in `components/`)
or data (that goes in `content/`).
