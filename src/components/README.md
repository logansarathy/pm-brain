# components/

**What goes here:** Small, reusable pieces of UI that get used in many places —
things like `<ProgressRing>`, `<StatCard>`, `<Toast>`, `<EmptyState>`.

**Rule of thumb:** if you could imagine using this piece of UI on more than
one page, it belongs here.

**You will edit this folder:** often — every time you want to reuse a visual
element in a second place.

**You will NOT put here:** a full page like "Dashboard" or "Week 1" — those
go in `pages/`.
