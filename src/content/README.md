# content/

**What goes here:** The actual PM OS course data — your weeks, lessons, and
default state, matching `defaultState()`, `defaultLessons()`, `emptyWeek()`
from the HTML version.

**Why separate from types/:** types/ says what shape data must have; content/
is the real data itself, written in that shape.

**Why this is powerful:** later, editing a lesson's text becomes editing one
readable file here, instead of hunting through a giant JS function.

**You will edit this folder:** every time you add/edit a week or lesson's
actual content.
